# Realmwalker

## Project Option
Simple Browser Game

## Project Description
Realmwalker is a browser-based adventure game inspired by the Nine Realms of Norse mythology. Players travel through each realm, making difficult choices that affect their health and determine whether they survive the journey. Each decision includes an element of chance, creating a different experience with every playthrough.

## Theme Interpretation
This project interprets the theme of **Space** as different realms rather than outer space. Instead of traveling between planets, the player journeys through the Nine Realms of Norse mythology, treating each realm as a unique world with its own challenges and decisions.

## Intended User or Player
Realmwalker is intended for players who enjoy fantasy settings, mythology, and simple choice-based adventure games. The game is designed to be easy to understand while still providing meaningful decisions.

## User or Player Goal
The player's goal is to survive all nine realms by making choices, managing their health, and successfully completing encounters until reaching the final ending.

## Main Features
- Nine unique realm encounters
- Choice-based gameplay
- Health system
- Dice rolling mechanic
- Progress bar
- Decision counter
- Multiple endings based on player performance
- Restart option

## JavaScript Features
The JavaScript controls the game's interactive systems, including:
- Starting the game
- Loading each realm and its choices
- Dice rolling animation
- Random success and failure outcomes
- Health updates
- Progress tracking
- Ending summaries
- Restart functionality

## Responsive Design
The game uses responsive CSS and a media query to ensure the layout works on both desktop and mobile screen sizes. Buttons resize appropriately, content remains readable, and the game stays usable on smaller screens.

## User Testing
The game was tested by multiple users. Testers found the gameplay easy to understand and enjoyed the choice-based mechanics and dice rolling system. They suggested improving the clarity of the probability system, adding a progress indicator, improving visual feedback, and making the game more visually engaging.

## Revisions
Based on user feedback, the following improvements were made:
1. Added a progress bar to show journey completion.
2. Changed percentages to clearer "Chance of Success" labels.
3. Displayed the required dice roll before rolling.
4. Added better success and failure feedback.
5. Improved the ending summary with player statistics.
6. Adjusted game balance so losing is a realistic possibility.
